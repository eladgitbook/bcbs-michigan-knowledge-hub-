# BCBS Michigan Knowledge Hub

Source for the BCBS Michigan internal knowledge management site. Each top-level folder is a separate GitBook space; content is synced via Git Sync once configured.

| Folder | Space | Description |
|---|---|---|
| `home/` | Home | Welcome portal and announcements |
| `it-systems/` | IT & Systems | Internal tools, helpdesk, security |
| `operations/` | Operations & Processes | SOPs, department guides, compliance |
| `api-reference/` | API Reference | Internal API documentation |
