# Security Policies

BCBS Michigan handles protected health information (PHI) and is subject to HIPAA, state insurance regulations, and internal security requirements. All employees are responsible for understanding and following these policies.

## Key Policies

### Acceptable Use Policy
- Company devices are for business use. Limited personal use is permitted but monitored.
- Do not install unapproved software — see [Software Licenses](../systems-tools/software-licenses.md).
- Do not access, copy, or transmit PHI outside of approved systems.
- Use only approved cloud storage (SharePoint/OneDrive) — not personal Google Drive, Dropbox, etc.

### Password Requirements
- Minimum 14 characters
- Must include uppercase, lowercase, number, and symbol
- Change every 90 days (enforced by Active Directory)
- Never reuse the last 12 passwords
- Use the corporate password manager (1Password Teams) for credentials

### Data Classification

| Level | Examples | Handling |
|---|---|---|
| **Public** | Press releases, public website | No restrictions |
| **Internal** | Policies, org charts, meeting notes | Internal systems only |
| **Confidential** | Employee data, financials, contracts | Encrypted, need-to-know access |
| **PHI / Restricted** | Member health data, claims | HIPAA-regulated, audit logged |

### Remote Work Requirements
- Always connect via VPN when accessing internal systems remotely
- Lock your screen (`Win+L` / `Ctrl+Cmd+Q`) when stepping away
- Do not use public WiFi without VPN active
- Ensure no unauthorized persons can view your screen

## Reporting a Security Incident

{% hint style="danger" %}
**Suspected breach or phishing?** Report immediately — do not delay.

- **Email:** [security@bcbsm.com](mailto:security@bcbsm.com)
- **Phone:** Security Hotline x4911 (24/7)
- **Teams:** BCBSM Security Response channel
{% endhint %}

Examples to report: clicking a suspicious link, receiving unusual account activity alerts, losing a device, or noticing unauthorized data access.
