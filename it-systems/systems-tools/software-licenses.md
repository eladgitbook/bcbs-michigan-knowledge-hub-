# Software Licenses

BCBS Michigan maintains enterprise licenses for approved software. Installing unapproved software on company devices is prohibited by the [Acceptable Use Policy](../network-security/security-policies.md).

## Approved Software Categories

### Productivity
- Microsoft 365 (E5 license — all employees)
- Adobe Acrobat DC (licensed seats — request via ServiceNow)
- Zoom (all employees)

### Analytics & Data
- Microsoft Power BI Pro (data and analytics roles)
- Tableau (select business units — request required)
- SAS (actuarial and data science teams)

### Development
- GitHub Enterprise (engineering and IT)
- JetBrains Suite (software engineers)
- Visual Studio Code (all engineering staff)
- Postman (API developers)

## Requesting New Software

1. Submit a **Software Request** via ServiceNow
2. Include business justification and estimated number of users
3. IT Security will review within 5 business days
4. Approved software is added to Company Portal / Self Service for deployment

{% hint style="warning" %}
**Free trials of unapproved SaaS tools** still require IT Security review before use with any BCBS Michigan data. Submit a request before trialing.
{% endhint %}
