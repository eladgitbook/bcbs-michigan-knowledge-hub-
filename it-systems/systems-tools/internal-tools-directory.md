# Internal Tools Directory

A complete list of enterprise applications used at BCBS Michigan, with access instructions and key contacts.

## Core Platforms

| Tool | Purpose | Access |
|---|---|---|
| **Microsoft 365** | Email, Teams, Office apps | Auto-provisioned on hire |
| **Workday** | HR, payroll, time & attendance | `workday.bcbsm.com` |
| **ServiceNow** | IT ticketing, service catalog | `bcbsm.service-now.com` |
| **Zoom** | Video conferencing | Install via Company Portal |
| **SharePoint** | Document management, intranet | `bcbsm.sharepoint.com` |

## Business Applications

| Tool | Purpose | Access |
|---|---|---|
| **Claims Management Portal** | Claims adjudication and review | Request via ServiceNow → App Access |
| **Provider Portal** | Provider directory management | Request via ServiceNow → App Access |
| **Member 360** | Member account management | Request via ServiceNow → App Access |
| **Facets** | Core insurance platform | Requires role-based access + training |
| **Power BI** | Reporting and analytics | Request via ServiceNow → App Access |

## Development & IT Tools

| Tool | Purpose | Access |
|---|---|---|
| **GitHub Enterprise** | Source code management | `github.bcbsm.com` — request via ServiceNow |
| **Jira** | Project and issue tracking | `jira.bcbsm.com` |
| **Confluence** | Technical documentation | `confluence.bcbsm.com` |
| **Splunk** | Log management and SIEM | Security team access only |
| **Datadog** | Infrastructure monitoring | Engineering team access |

## Requesting Access

{% hint style="info" %}
All application access requests go through **ServiceNow**. Navigate to **Service Catalog → Access Request** and select the application. Your manager will be notified for approval.

**Standard processing time:** 1–2 business days for most apps; 3–5 for Facets and Claims Management Portal (requires training completion).
{% endhint %}
