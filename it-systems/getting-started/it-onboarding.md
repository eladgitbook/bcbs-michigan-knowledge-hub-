# IT Onboarding

Welcome to BCBS Michigan! This guide walks you through everything you need to get your technology environment set up on day one.

{% hint style="success" %}
**Target:** Complete all steps within your first 3 business days. Your manager and IT sponsor will help if you get stuck.
{% endhint %}

## Onboarding Checklist

{% stepper %}
{% step %}
### Collect Your Credentials

Your IT sponsor will provide:
- Employee ID and network username
- Temporary password (must be changed on first login)
- Badge access activation email

**Change your password at:** `https://password.bcbsm.com`
{% endstep %}

{% step %}
### Set Up Multi-Factor Authentication

BCBS Michigan requires MFA on all accounts.

1. Download **Microsoft Authenticator** on your mobile device
2. Go to `https://aka.ms/mysecurityinfo`
3. Add your BCBS Michigan account and follow the prompts
4. Test a login to confirm MFA is working
{% endstep %}

{% step %}
### Connect to the Network

**In-office:** Connect to the `BCBSM-Corp` WiFi network using your employee credentials.

**Remote:** Install and configure the VPN client — see [VPN Access](../network-security/vpn-access.md) for full instructions.
{% endstep %}

{% step %}
### Install Core Applications

Submit a request through ServiceNow for your role-specific software bundle. Standard installs include:

- Microsoft 365 (Outlook, Teams, Office)
- Workday (HR and time tracking)
- ServiceNow (IT ticketing)
- Zoom

See [Internal Tools Directory](../systems-tools/internal-tools-directory.md) for a full list.
{% endstep %}

{% step %}
### Complete Security Training

All new employees must complete security awareness training within 30 days:

1. Log in to Workday
2. Navigate to **Learning → Assigned Courses**
3. Complete **Information Security Fundamentals** (approx. 45 minutes)
{% endstep %}
{% endstepper %}
