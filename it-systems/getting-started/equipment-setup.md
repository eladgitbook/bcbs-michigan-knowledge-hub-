# Equipment Setup

Setup instructions for BCBS Michigan-issued laptops, monitors, and peripherals.

## Laptop Setup

{% tabs %}
{% tab title="Windows (Dell)" %}
1. Power on and connect to `BCBSM-Corp` WiFi or ethernet
2. Sign in with your employee username (`firstname.lastname@bcbsm.com`)
3. Windows will auto-enroll in Intune MDM — allow up to 20 minutes
4. Restart when prompted to complete configuration
5. Install remaining apps via **Company Portal**
{% endtab %}

{% tab title="MacBook (Apple)" %}
1. Power on and follow the Setup Assistant
2. Sign in with your **Apple ID** only when prompted (personal Apple ID is fine for iCloud; BCBSM apps use your employee account)
3. Connect to `BCBSM-Corp` WiFi
4. Open **Self Service** (pre-installed) and run the BCBSM configuration profile
5. Install required apps via Self Service
{% endtab %}
{% endtabs %}

## Monitor & Peripherals

Standard workstation setup includes one or two external monitors. Dock stations are available at all campus desks.

{% hint style="info" %}
**Docking stations:** Use the Dell WD19S dock for Windows laptops and the Thunderbolt dock for MacBooks. Both support dual 4K displays.
{% endhint %}

## Requesting Additional Equipment

Submit a request in **ServiceNow** under **Hardware Request**. Include your manager's name for approval routing. Standard lead time is 3–5 business days.
